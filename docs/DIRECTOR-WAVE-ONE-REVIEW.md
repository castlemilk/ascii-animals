# Director wave one: bounded integration review

This candidate integrates recovered, species-owned director work for ten animals:
Cuttlefish, Manta, Octopus, Pufferfish, Fox, Butterfly, Owl, Seahorse, Crab and Turtle.
It preserves each species' distinct typed API and the shared scheduler. It does
not claim an identical cross-species director contract or complete Cuttlefish parity.

## Source and actual browser acceptance

- Fox PR23 `ab1ea989`: three meadow scenes, bounded cast and individual motives;
  independent desktop/390px, pause/replay, still-tableau and reduced-motion checks.
- Butterfly PR22 `5b35351`: four garden arcs, botanical composition and 1–6 visitors;
  independent desktop/390px, scene/act/role editing, pause and static invitation.
- Owl PR24 `45a713d`: three scenes, duet roles and perch compositions; desktop/390px,
  pause, solo/duet and reduced-motion checks. Calls are visual, not audio.
- Marine/Puffer PR25 `e9bef170`: mixed marine scene direction and Puffer company;
  actual desktop/mobile review found and fixed offscreen explicit cues being rejected.
  Explicit below-canvas cues now compose a still pose without starting animation.
  Puffer's copied marine runtime is regenerated from the canonical source.
- Coastal `9a7f119`: distinct Seahorse kelp duet, Crab tidepool/council and Turtle reef
  ensemble. Each independently checked on desktop/390px with selected roles/cues,
  paused scene changes and reduced-motion reload. Source artifacts were recovered,
  not independently reimplemented; source file inventories and native evidence remain.

These are actual Chrome observations, separate from authors' native Canvas captures.
No blocking defect was observed in this subset. Browser tooling stalled for hours
on some emulation calls; that is tool latency, not measured artwork performance.

## Deliberate limits and excluded work

Frog's director is excluded: browser review found black canvas/stale scene labels
following viewport/motion transitions. Its existing released solo study is retained.
Dragonfly/Gecko director work is excluded pending final mobile/reduced-motion checks;
their existing released studies are retained. Further imports must not overwrite
these accepted source histories or regenerate stale shared runtime copies.

Bounded acceptance is not creative completion. Fine mobile detail, crowded-ensemble
crossings and some subtle answering gestures remain imperfect or unmeasured. No
physical touch-device, systematic screen-reader/contrast audit, exhaustive phase
coverage, export/download matrix, performance/heap, or broad browser certification
is claimed. Optional package toolchain checks are reported separately by the harness.
The package remains private, UNLICENSED and unpublished to npm.
