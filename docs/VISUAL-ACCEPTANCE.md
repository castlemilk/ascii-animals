# Bounded independent visual acceptance

The combined thirteen-animal candidate was reviewed in actual Chrome on the Mac, primarily through the integrated local site. No visual pass is inferred solely from automated state labels or numerical tests.

| Study | Independently observed |
|---|---|
| Cuttlefish | School controls, targeted reactive behavior, pause/reset, reduced motion, source viewer, mobile, styled standalone; PNG and recording in the earlier canonical review. |
| Manta | Distinct broad wings, forward lobes and slender tail; mixed school and pause/reset; no ink observed. |
| Octopus | Recognizable silhouette and a **clearly visible violet ASCII ink plume** after retreat; mixed school, mobile and reduced-motion startup. |
| Fox | Pointed ears/muzzle/broad tail/legs, preparing and airborne pounce, guide/sniff, mirrored pose, pause/reset, mobile, static reduced-motion reaction and actual ASCII text capture. |
| Dragonfly | Four wings/paired eyes/long abdomen; dorsal and neutral views, dart, guide/slow/still, pause/reset, mobile and static reduced-motion pose. |
| Gecko | Broad head/body, four pad feet and attached tail; guide/startle with visibly curled tail, pause/reset, mobile, reduced-motion still portrait and character-text fallback. |
| Pufferfish | Recognizable fish, visibly enlarged spiny body and contraction/recovery; mobile, static calm/inflated reduced-motion poses, paused reset. Tested against combined marine dependencies. |
| Frog | Squat body/bulging eyes/folded legs, airborne leap toward the target, static extended-leg pose, pause/reset, reduced-motion still crouch and mobile. |
| Owl | Facial disk/eyes/folded wing/feet on branch, guided head turn, blink/ruffle, static wing stretch, pause/reset, reduced-motion resting and mobile. |
| Seahorse | Upright distinctive silhouette and curled tail, holdfast/greet, pause and narrow layout; corrected reduced-motion playback label rechecked. |
| Crab | Broad shell/eyes, two claws and eight-leg silhouette, visible guard/alert gestures, pause/reset, mobile and static reduced-motion defence. |
| Turtle | Patterned domed shell/head/four flippers/tail, approach/inspect, pause/reset, mobile and static reduced-motion streamline. |
| Butterfly | Four patterned fore/hind wings, central body and antennae; open-wing perch and approach, pause/reset, mobile and static reduced-motion display. |

No console errors were observed in the reviewed flows. Reviewers cleared their temporary viewport/media overrides. Findings fixed before release: dark-on-dark octopus ink, misleading reduced-motion playback labels, stale Owl integration copy and Gecko catalogue navigation.

## Limits

This is bounded Chrome acceptance, not exhaustive cross-browser, scientific-anatomy, full assistive-technology, GPU/performance or heap-retention certification. Every gait/support phase, exact retreat trajectory and precise Pufferfish cooldown/intermediate inflation timing were not independently measured. Low-grid octopus arms can overlap. Direct `file://` standalone execution was blocked by browser-tool policy in the canonical review; HTTP self-contained rendering and reproducibility were checked. No blanket download/export claim is made for species without that UI.

The package remains private and unpublished to npm. Source acceptance and Pages release do not authorize registry publication.
