Embed the existing cuttlefish

A procedural cuttlefish swims and reacts in a canvas. The artwork starts still. Use Play to request animation, Pause to stop, or Startle for a deliberate reaction while it is running.

Your browser needs Canvas 2D to display the artwork. The controls below describe its playback state.

Preparing the still artwork…

Animation stays paused while reduced motion is requested, the page is hidden, the canvas is outside the viewport, or its display size is zero. A Play request remains remembered until Pause; it resumes when all those conditions clear.

This review example uses the existing browser renderer. Its internal frame callback remains scheduled while paused. The adapter adds no animation loop or status polling. Browser and assistive-technology acceptance are still required.
